## 4. Who owns what

- **Backend and PostgreSQL**: the one source of truth for the run lifecycle (arbiter, fences, deadline, CAS), learned memory (L2b), the AI gateway (L1-gw), deterministic validators and conformance (L1/L2c), native writers, reconciliation, and the one run-status projection (L2d). It also generates the importer OpenAPI contract (`scripts/importer-contract.ts`, the only generator owner).
- **Mobile**: the Roman journey. Picks the source, creates the intent, shows the pairing code, reads status, presents the verdict. It only decodes values from the server and invents no authority.
- **Extension**: the executor. One Start = authorize one origin (D9). It observes, builds a value-free digest, replays under the read-only and credential invariants, ingests, and claims. It never decides the terminal state. The popup is a status surface.
- **AI**: returns data-only proposals through the `importer.mapping` capability. It never decides identity, writes, or `complete`.
- **Shared contracts**: backend OpenAPI, mobile decoders (unknown values map to `unknown`), and the L1 fixture mirrors (`admission-rules.json`, `fingerprint-vectors.json`) that the extension copies byte for byte.
