- `:72-80` (`attemptRunAt`) and the two settle calls (`:226`, `:236`): the 6 hours count from the start of the run that made the attempt, the same clock as built_at (the run's `now`). Both settles now store `run_at: now.toISOString()` in the row's metadata; a row without it (a reservation that was never settled) counts from its created_at. Reason: the reservation row is created when the run reaches the coach, which can be minutes after the run started; counting from that time would make the next 6-hourly run skip the coach, so a failing coach, and a coach whose playbook changed, would wait 12 hours.
